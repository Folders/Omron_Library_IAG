# Sysmac Studio Interactive Graphics (IAG) Library

This repository contains a collection of well-structured and reusable **Interactive Graphics (IAG)** objects for use in **Sysmac Studio HMI projects**. The primary goal of this library is to provide graphical components that are fully integrated with the Function Block (FB) structures from the [Omron_Library_FB project](https://github.com/Folders/Omron_Library_FB). This ensures consistency, modularity, and ease of use across HMI and PLC programming.

## About This Project
- **Experience**: Built upon over 15 years of expertise in industrial automation and Omron solutions.
- **Integration**: Designed to align with the structures and conventions defined in the [Omron_Library_FB project](https://github.com/Folders/Omron_Library_FB), ensuring seamless communication between HMI graphics and PLC logic.
- **Scope**: Includes graphical objects such as buttons, indicators, and custom controls for intuitive and efficient HMI design.
- **Goal**: Standardize HMI graphics using modern techniques and ensure compatibility with advanced PLC programming structures.
- **Collaboration**: Users are invited to suggest improvements or request specific components to prioritize their needs.

## Key Features
- **Consistency**: Adheres to the same naming and structural conventions as the Omron FB library.
- **Reusability**: Provides modular graphics that can be easily integrated into different HMI projects.
- **Efficiency**: Simplifies HMI development with pre-designed, functional graphics.

For more details on usage and implementation, refer to the [Wiki](#), where examples and best practices are provided to help integrate this library into your Sysmac Studio HMI projects.
